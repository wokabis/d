## How to read the tables

- **Works with** names the client an extension targets: Claude Code, Codex, Gemini CLI, OpenCode, Kimi Code, Grok Build, DeepSeek Harness, Cursor, Copilot CLI. `MCP` means any Model Context Protocol client. `Skills` means portable SKILL.md packages. `Multi` means the entry ships adapters for several clients. `Standalone` means it runs on its own.
- **Pricing** uses a fixed vocabulary: `Free`, `Freemium`, `Paid`, `Open Source`, `Free Trial`.
- **License** and **Hosting** come from each project's own documentation. `Self-hosted` means you run it; `Vendor-hosted` means they run it; `Local` means it never leaves your machine.
- **Form** describes the delivery: Library, CLI, Desktop, Web app, API, Extension, Dataset, Benchmark, Guide.
- Every link points to the official repository or product page. Nothing in this library is paid placement.

## Curation rules

1. Every entry does one job, and the table says what that job is.
2. Entries are grouped by the outcome you are buying, not by who shipped them.
3. Dead, rebranded, or absorbed tools get corrected or removed, not kept for volume.
4. Descriptions are written for this library — never lifted from a vendor homepage.
5. No badges, sponsorships, or contribution mechanics. This library is for reading, not farming.
