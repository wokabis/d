# Official Plugins

> Vendor-blessed integrations: the built-in Codex plugin directory, curated by OpenAI, plus the first-party agent-skills pack that inspired the catalog. Each of these is a known quantity — a named service with a stable API.

## The built-in Codex directory

OpenAI's Codex ships a curated directory of first-party integrations. One install, and these work inside Codex.

| Service | What it does |
| :------ | :----------- |
| [Box](https://www.box.com/) | Access and manage files. |
| [Cloudflare](https://www.cloudflare.com/) | Manage Workers, Pages, DNS, and infrastructure. |
| [Figma](https://www.figma.com/) | Inspect designs, extract specs, and document components. |
| [GitHub](https://github.com/) | Review changes, manage issues, and interact with repositories. |
| [Gmail](https://mail.google.com/) | Read, search, and compose emails. |
| [Google Drive](https://drive.google.com/) | Edit and manage files in Google Drive. |
| [Hugging Face](https://huggingface.co/) | Browse models, datasets, and spaces. |
| [Linear](https://linear.app/) | Create and manage issues, projects, and workflows. |
| [Notion](https://www.notion.com/) | Create and edit pages, databases, and content. |
| [Sentry](https://sentry.io/) | Monitor errors, triage issues, and track performance. |
| [Slack](https://slack.com/) | Send messages, search channels, manage conversations. |
| [Vercel](https://vercel.com/) | Deploy, preview, and manage Vercel projects. |
