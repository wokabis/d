## Vocabulary

- **Agent Skill / SKILL.md** — portable instructions a compatible agent loads on demand.
- **Plugin** — a client-specific bundle with its own manifest (`plugin.json`).
- **MCP server** — a tool that any Model Context Protocol client can call.
- **Multi** — one repo shipping adapters for several clients.

Targets named in the pages: Claude Code, Codex CLI/Desktop, Cursor, Windsurf, Gemini CLI, Grok Build, Kimi Code, DeepSeek Harness (DSH), OpenCode, Copilot CLI, pi, OpenClaw, Hermes, Antigravity, Qwen Code, ZCode, omp, herdr. `Standalone` means it runs on its own, not inside a client.

## Security note

Nothing here is a safety guarantee. The catalog is an editorial repository, not a certification body. Before installing software or connecting a server, read the project's own README, trust verifiable publishers, and keep secrets local.
