# 04 · LLM Apps and Templates

> Open-source agents, agent skills, and RAG apps you can run today. Hand-built, tested end-to-end, Apache-2.0. Fork, run, sell — free and open.

Works with Claude, Gemini, GPT, DeepSeek, Llama, Qwen, and other open-source models. Templates are grouped by outcome. Paths are relative to the upstream collection that hosts the code.

## Agent skills

Give your coding agent new abilities. One command to install, plain English to use.

| Skill | What it does |
| :---- | :----------- |
| Project Graveyard | Finds every side project you abandoned, tells you why each died, and helps you finish the one worth returning to. |
| First Reader | Simulates real readers going through your draft and reports where they lose interest, stop, and what they remember — without rewriting a word. |
| Scope Creep Detector | Checks whether a diff grew beyond its stated intent and recommends what to keep, split, or justify. |
| Commit Archaeologist | Reconstructs why a file or code region exists from its introducing commit, later edits, co-changes, and intent clues. |
| Dependency Doctor | Checks a dependency manifest for standard-library pins, obsolete backports, unpinned entries, duplicate constraints, and yanked releases. |
| Advisor Orchestrator Worker | Meta loops pairing an advisor, an orchestrator, and a worker. |

| Self-Improving Agent Skills | Automatically optimizes agent skills using Gemini and ADK. |
