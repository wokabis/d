# 05 · Tool Directory

> The finished, everyday software worth knowing — the short version. Grouped by the job you are trying to get done, every entry linking to the product's own site.

There are far more AI tools than anyone can evaluate. This is the practical subset: tools that solve a problem, today, in production. Pricing uses a fixed vocabulary (`Free`, `Freemium`, `Paid`, `Open Source`, `Free Trial`) because exact prices go stale within weeks.

## How tools are chosen

- The tool has a working official website and is actively available.
- AI is central to what it does, not a feature bolted onto the marketing page.
- It solves a problem someone would recognise without a demo.
- There is enough public information to describe it accurately.
- It adds something the other tools in its category do not cover.

Tools stay out when a site is broken or parked, the product is abandoned, the page is pure affiliate bait, or the tool is a near-identical clone. Ordering is alphabetical; position carries no meaning. No paid placement anywhere in this directory. Listing is an editorial decision, not an endorsement — check the vendor before committing money or data.
